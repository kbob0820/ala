# System Overview

## Purpose
Ajang Loan System manages the complete loan lifecycle for lenders operating on Web, Android and iOS.

## Scope
- Borrower management
- Loan origination
- Payment processing
- Reloan
- Collections
- Refunds
- Reports
- Notifications
- Audit logs

## Core Features
- Gross loan with configurable deductions
- Net proceeds computation
- Twice-per-month payment schedule
- Payment proof upload
- Role-based access
